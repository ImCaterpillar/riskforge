# 开发路线图（Milestone Roadmap）

本文件是 riskforge 的**真实开发计划**。每个里程碑都是"一项需求做完"，交付外部可观测的能力
（新 CLI/输出文件/接口/数据结构），并配单元测试。里程碑按真实开发顺序推进，历史不回填。

> 提交到数据平台时，里程碑边界以 `repo_audit.py milestones` 对**真实 git 历史**的切分为准，
> 再人工按"一项需求做完、≥10 个代码文件、>2000 行 diff、相邻首尾相接"复核；本路线图只指导开发顺序。

| 里程碑 | 主题 | 对外可观测交付 | 主要新增模块 | 状态 |
|---|---|---|---|---|
| **M0** | 工程骨架 | 可安装的包布局、打包配置、依赖策略、LICENSE、README | `pyproject.toml`、包初始化、文档 | ✅ 完成 |
| **M1** | 市场数据层 | `data synth/validate` CLI、CSV 读写、合成数据文件、复权与校验 | `riskforge.data.*`、`tests/` | ✅ 完成 |
| **M2** | 指标与策略接口 | 技术/统计指标输出、策略信号 API、信号 CSV | `riskforge.indicators`、`riskforge.strategy`、信号 CLI | ✅ 完成 |
| **M3** | 事件驱动回测引擎 | 订单/成交/持仓/净值序列、手续费滑点、回测结果 JSON | `riskforge.engine`、组合与撮合、回测 CLI | ⏳ |
| **M4** | 绩效与风险指标 | 年化/夏普/最大回撤/卡玛/胜率、VaR/CVaR、基准对比报告字段 | `riskforge.risk`、指标单测 | ⏳ |
| **M5** | 参数寻优与稳健性 | 网格/ walk-forward 结果文件、过拟合防护、并行 | `riskforge.opt`、寻优 CLI | ⏳ |

| **M7** | 数据适配与批量实验 | 真实数据适配器接口、批量回测实验清单、结果汇总 | `riskforge.adapters`、实验运行器 | ⏳（可选） |

## 每个里程碑的"完成定义"

- [ ] 交付一项**外部可观测**的新能力（CLI 子命令、输出文件格式、公开接口或数据结构）；
- [ ] 起点 commit 上该能力不存在/跑不过，终点 commit 上可运行并有通过的测试断言；
- [ ] 新增/修改 ≥10 个代码文件、累计 >2000 行 diff（含测试），围绕同一需求；
- [ ] `python -m unittest discover -s tests` 全绿，核心仍零第三方依赖（可选依赖除外）；
- [ ] 区间内无关改动在提交说明与备注中注明；
- [ ] 不提交密钥、客户数据、内网地址。

## 开发节奏与合规

- 里程碑在**不同日期的真实会话**中推进，提交时间戳保持真实，不批量回填、不一次性灌仓；
- AI 辅助编码（补全、重构、生成测试）允许，但设计与取舍需真实发生、可在提交说明/设计记录中追溯；
- 重要设计决策记录到 `docs/decisions/`（按需新增），作为开发过程证据。
